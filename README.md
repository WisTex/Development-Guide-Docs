# Development Documentation Repository

This repository contains source documentation for Hubzilla, OpenWebAuth, Neuhub, WisTex projects, and related technologies.

The repository serves as the canonical source for public-facing documentation. Documents may be published on one or more websites, including development.guide, neuhub.org, federatedhub.org, and future WisTex platforms.

## Philosophy

Documentation should be:

* Written in Markdown
* Human-readable
* AI-friendly
* Easy to version and review
* Independent of any specific publishing platform

Documents in this repository are the source of truth. Published websites are considered distribution channels rather than the authoritative source.

## Repository Structure

```text
docs/
    Documentation source files

style-guides/
    Site-specific styling and conversion guidance

publishing-targets/
    Site-specific publishing instructions
```

## Publishing Workflow

1. Create or update a Markdown document.
2. Commit changes to Git.
3. Convert Markdown to HTML using the appropriate style guide.
4. Publish to one or more websites.
5. The Markdown document remains the authoritative source.
