# What Is Neuhub?

## Overview

Neuhub is a collection of themes, addons, widgets, and related software components for Hubzilla.

The project focuses on improving usability, appearance, functionality, and site development while building on Hubzilla's existing extension architecture.

## Why Neuhub Exists

Hubzilla is one of the most capable federated platforms available today. It provides features such as nomadic identity, advanced privacy controls, decentralized publishing, cloud storage, collaboration tools, and website creation.

Despite these strengths, many potential users encounter challenges during onboarding. The default user experience can be confusing, documentation may be difficult to find, and some features are not presented in a way that clearly communicates their value.

Neuhub exists to address these challenges without requiring fundamental changes to Hubzilla itself.

By improving user interfaces, visual design, onboarding experiences, and reusable software components, Neuhub helps make Hubzilla's existing capabilities more accessible to a broader audience.

## Goals

The goals of Neuhub include:

* Creating reusable themes
* Developing addons and widgets
* Improving user experience and usability
* Modernizing visual design
* Reducing development effort for site operators
* Encouraging consistency across related projects
* Demonstrating what is possible with Hubzilla
* Accelerating the development of Hubzilla-based websites

## Relationship to Hubzilla

Neuhub is not a fork of Hubzilla and is not intended to replace Hubzilla.

Instead, Neuhub extends Hubzilla through supported extension mechanisms such as:

* Addons
* Widgets
* Themes

Whenever practical, Neuhub builds on Hubzilla's existing extension architecture rather than modifying Hubzilla core.

This approach helps maintain compatibility with future Hubzilla releases while reducing maintenance requirements.

## Areas of Focus

Neuhub projects may include both deployable components and supporting resources.

### Deployable Components

The primary deliverables of Neuhub are software components that can be installed and used on Hubzilla websites.

Examples include:

* Themes
* Addons
* Widgets

### Supporting Resources

Neuhub may also provide supporting resources that help developers build their own solutions.

Examples include:

* Example code
* Template collections
* Design systems
* User interface patterns
* Administrative tools
* Developer tools
* Integration components

These resources are intended to support development and adoption but are generally not considered primary Neuhub deliverables.

## Design Philosophy

Neuhub favors supported extension mechanisms over core modifications whenever practical.

Projects should be easy to deploy, easy to maintain, and easy to reuse.

Whenever possible, functionality should be packaged in a way that allows it to be adopted independently without requiring large-scale changes to an existing site.

Reusable components are generally preferred over one-off customizations.

## Long-Term Vision

The long-term vision of Neuhub is to provide a growing ecosystem of reusable components that make it easier to build, customize, and maintain Hubzilla-powered websites.

By reducing development effort and improving usability, Neuhub helps site operators focus on building communities, services, and content rather than repeatedly solving the same technical problems.

## Conclusion

Neuhub is a collection of themes, addons, widgets, and related software components designed to enhance the Hubzilla ecosystem.

Its purpose is to make Hubzilla sites easier to build, easier to customize, and easier to use while remaining compatible with the platform that makes them possible.
